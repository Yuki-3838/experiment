# Astraeus Helios 配置数値一覧

すべてUnityのローカル座標で、数値の順序は `(X, Y, Z)` です。前方は `+Z`、上は `+Y` です。

## 機体本体

| 項目 | 値 |
|---|---|
| 名前 | Astraeus |
| Position | `(0, 0, 0)` |
| Rotation | `(0, 0, 0)` |
| Scale | `(1, 1, 1)` |
| AIクラス | `Astraeus.Astraeus` |
| 表示機体名 | Astraeus - Helios |
| 実測コスト | 319 |
| 出撃回数 | 初期エネルギー1,000で3回 |

## 砲台と回転ジョイント

砲台は標準の `TurretPart`、回転ジョイントは標準の `RotJointPart` を使用します。

| 名前 | 親オブジェクト | Local Position | Local Rotation | Local Scale |
|---|---|---|---|---|
| AstraeusFireControlRing | Astraeus | `(0, 0.12, 0)` | `(0, 0, 0)` | `(1, 1, 1)` |
| AstraeusGun_0 | AstraeusFireControlRing | `(-0.66, 0, 1.05)` | `(0, 0, 0)` | `(1, 1, 1)` |
| AstraeusGun_1 | AstraeusFireControlRing | `(0, 0, 1.05)` | `(0, 0, 0)` | `(1, 1, 1)` |
| AstraeusGun_2 | AstraeusFireControlRing | `(0.66, 0, 1.05)` | `(0, 0, 0)` | `(1, 1, 1)` |

砲台のY=0はジョイントからの相対位置です。初期姿勢では機体本体からの高さが0.12になります。

AIの `m_turrets` 配列には Gun_0、Gun_1、Gun_2 の順に3基、`m_rotJoints` 配列には FireControlRing を1基登録します。

## 装甲67枚

すべて標準Cubeで作成し、親は機体本体の `Astraeus`、Local Rotationは `(0, 0, 0)` です。Local Scaleが各Cubeの大きさになります。

`±` はプラス側・マイナス側の両方を作る意味です。複数のX・Z値がある場合は、すべての組み合わせで作成します。

### 外側装甲：17枚 × 3層 = 51枚

各層について、下の5種類を作ります。

| 種類 | Local Position | Local Scale | 各層の枚数 |
|---|---|---|---:|
| 車体側面 | `(±A, 0.07, Z)`：Zは `-1.10, 0, 1.10` | `(0.06, 0.80, 1.12)` | 6 |
| 車体前後 | `(X, 0.07, ±B)`：Xは `-0.94, 0, 0.94` | `(0.96, 0.80, 0.06)` | 6 |
| 操縦席側面 | `(±C, 0.92, 0)` | `(0.05, 1.26, 1.20)` | 2 |
| 操縦席前後 | `(0, 0.92, ±C)` | `(1.20, 1.26, 0.05)` | 2 |
| 操縦席天板 | `(0, D, 0)` | `(1.30, 0.05, 1.30)` | 1 |

層ごとのA～Dの値です。

| 層 | A | B | C | D |
|---|---:|---:|---:|---:|
| 1層目 | 1.330 | 1.580 | 0.54 | 1.56 |
| 2層目 | 1.415 | 1.665 | 0.62 | 1.63 |
| 3層目 | 1.500 | 1.750 | 0.70 | 1.70 |

例：2層目の車体側面は `(-1.415, 0.07, -1.10)`、`(-1.415, 0.07, 0)`、`(-1.415, 0.07, 1.10)` と、Xを `+1.415` にした3枚の計6枚です。
