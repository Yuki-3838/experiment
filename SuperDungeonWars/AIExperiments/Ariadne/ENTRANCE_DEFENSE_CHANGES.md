# 入口への配置・迎撃・復帰の改善 — 2026-10-29

独立した待ち伏せ版AriadneEntranceAmbushへの追加実装。固定タグ `superdungeonwars-ariadne-entrance-defense`。通常の回収版と共通C4クラスには変更を加えていない。

## 変更した判断

- **配置と復帰を優先**：初回、KO後、搬出後は担当入口の待機点へ戻り切るまで追跡・落下宝回収・一時探索へ移らない。待機中に0.6ワールド単位以上ずれた場合も復帰状態にする。行動ロック中は新しい移動を指示せず、解除後に戻る。
- **入口までの経路**：既知経路は、見えた通常敵の近傍へ追加コストを付けて迂回する。最短より最大4歩まで。0.9ゲーム内秒で0.15単位も進まない場合は直前の一歩を2秒間避ける候補を探す。迂回路がない場合は停止せず従来のBFSを用いる。敵の非公開位置やPhysicsの照会は使わない。
- **探索の寄り道を削減**：未接続の入口へ向かう開拓先を毎回比較する。前回目標を無条件で続行する処理を外し、移動距離をそのままコストに加える。前回目標は1歩相当だけ優遇し、小さな差での切り替えを抑える。完全未知の壁を通れるものとして移動する処理は加えていない。
- **横を通る運搬者へ接近**：落下宝より可視運搬者を先に狙う。同じセル、または既知通路で直接接続した隣セルなら相手の実座標へ移動し、セル中心に向かうだけの追跡を減らす。入口から3歩・本人から4歩までの相手が対象。迎撃は最大1.2ゲーム内秒で切り上げ、配置へ戻る。相手を見失った場合も戻る。
- **待機位置**：公開セル座標から進入方向を直交方向で記憶し、進入点から0.85ワールド単位内側を待機点とする。以前の0.12単位では境界寄りだった。復帰開始0.1単位・完了0.06単位の判定は維持する。セル間隔2という配布ルールを前提とする。
- **攻撃の優先度**：運搬者を護衛対象への脅威より先に選ぶ。入口役は通常敵への反撃を密着0.65単位以内に絞り、道中で攻撃による停止を繰り返すのを抑える。回収許可中と護衛対象への脅威は従来どおり。無抵抗や被KOを完全に防ぐ保証はない。
- **反応間隔**：待ち伏せ版の仕事の判断を0.12秒から0.06ゲーム内秒へ変更。セル到着時に同じ移動を継続する前版の仕組みも残す。

回収1人＋自陣以外の3入口へ各1人、共通C4推定、一時回収ON/OFF（初期OFF）は保持。落下宝の奪取は入口から2歩以内に狭めた。必要ファイルは待ち伏せ5本＋共通1本で変わらない。Party・Character用Prefabの参照を交換する必要はなく、Play中なら停止して再生し直す。

## 確認範囲と限界

コードを読み、落下宝の選択が運搬者迎撃より先だったこと、復帰が回収・迎撃に割り込まれる構造、未観測の開拓先を無条件で継続する処理を確認した。これらがユーザーの各試合の直接原因だったかは未確定。

Unity 6000.3.27f1の隔離プロジェクトへ最終C#をコピーし、batchmode/quitでコンパイルのみ確認した。Play、既存テスト、新規テスト、対戦比較は実行していない。迂回による到着時間短縮、横抜け阻止、実際の攻撃・KO後の帰還、勝率・得点の改善は未測定。前版の物理確認を今回の実測結果として扱わない。

復帰を優先する間は、運搬者への攻撃機会を逃す場合がある。1人の攻撃には射程とクールダウンがあり、通過を完全には封鎖できない。通路が1本しかなければ敵を迂回できず、反撃の距離制限が不利になる可能性もある。経路探索は歩数制約付きの近似で、候補がなければBFSへ戻す。

参加者コードは公開SXG API・公開観測とそのC4推定のみを利用。ゲーム本体・Prefab・meta・Registry・シーン・共通クラス・通常AIは今回の変更対象外。公開差分は待ち伏せC#3本と直接付随するMarkdownのみ。確認環境・ログ・生データはローカルに保存し、提出ZIP・正式提出用検査・自動開発は更新しない。
