# 追加強化2 — 2026-10-26

ユーザーから、4日目までの挙動について「全員が探索を続けて近くの宝を拾わない」「遠い宝を回収して運搬に時間がかかる」との報告を受け、回収の担当割当を変更した。

**対戦比較は行っていない。Unityのコンパイル・再生確認も未実施で、今回の変更の効果は未測定。** 過去の成績は当時の版の結果として残す。

## 原因として確認できた設計

以前は宝の回収と探索先を同じ評価値で比較していた。近い宝でも帰還距離などで評価が低くなれば、探索が先になる場合があった。また、宝の相対価値が高ければ遠い宝が選ばれ、複数人が長い回収に拘束される余地があった。

この設計上の可能性はコードから確認したもの。報告されたプレイそのものを再現して原因を確定したわけではない。

## 回収を先に割り当てる

運搬中の仲間へ帰還を指示した後、次の順で担当を決める。探索と回収の点数を競わせる処理をやめた。

| 順序 | 条件・判断 |
|---|---|
| 近場の回収 | 既知経路4歩以内、回収から搬出までの見積もり24秒以内。まず到着までの歩数、同じなら全工程の短さで選ぶ |
| それ以外の短い回収 | 拾うまで12歩以内、全工程24秒以内。相対価値/全工程の秒数で比較する |
| 長い回収 | 短い回収に該当しない仕事は同時に1人。全工程45秒以内、残り時間内という見積もりが必要 |
| 支援と探索 | 回収・搬出の担当を確保した後、残った仲間へ割り当てる |

全工程の概算は、往路0.72秒/歩＋運搬1.05秒/歩＋動作等の余裕3秒。通常速度3、運搬速度2、セル間隔2、120秒制が前提。直線距離ではなく、観測済み通路の経路長を使う。衝突・戦闘・危険回避の寄り道は正確に予測しない。

通常の回収・搬出へは最大3人を割り当て、1人分を探索等へ残す。ただし、条件を満たす近場の宝が全員分ある場合は、近場の回収を優先して4人を使える。近場以外では同じ宝の担当を15%優遇し、小さな効率差による目標変更を抑える。探索中の前回目標の18%優遇は維持する。

遠征として始めた仕事を同じ仲間が続ける間は、途中で宝へ近づいても運搬中まで遠征枠を保持する。KOで失った仕事や、他者に拾われて候補から消えた宝の割当は解除する。攻撃動作等で一時ロック中の担当も数え、回収先の予約を維持する。

24秒・45秒などの値は未調整の方針値。遠い高価値の宝を取り逃す可能性もあり、これによって得点が上がったとは確認していない。

## 宝をIDで追う

各回収担当に宝のIDを保持させ、目標セルに着いたら、その宝の観測済みワールド座標へ近づく。同じセルにある別の宝を、記憶一覧の順序だけで移動先にする処理をやめた。

## 相手側の入口へ搬出してよいか

この配布版の `Documents/GameRules.md` の「宝箱の持ち帰り」には、4チームのどの入口へ搬出しても運んだチームの得点になると明記されている。実装も搬出者のパーティーへ宝を加算している。

そのため自分の開始口へ限定せず、到達できる4入口から距離と可視の敵を考慮して帰還先を選ぶ。ただし、ルール上搬出可能であることと、敵が近くにいる入口へ運ぶ危険は別。追加強化1の可視の敵を避ける帰還経路は維持している。
