# 追加強化3 — 中央の金宝箱を優先（2026-10-26）

ユーザーの「中央の金宝箱は極力狙いたい」という指定に対応した追加実装。参加受付番号は **0004838**。固定版は [superdungeonwars-ariadne-upgrade3](https://github.com/Yuki-3838/experiment/tree/superdungeonwars-ariadne-upgrade3/SuperDungeonWars)。追加強化2と、2・3・4日目の固定タグも維持する。

## 変更した判断

1. 宝を持っている仲間の搬出を先に確保する。
2. 手ぶらで動ける仲間から、中央の金宝箱を狙う担当を最大1人、通常の回収より先に確保する。
3. ほかの仲間には近場の通常宝箱を先に割り当て、その後に短い回収・支援・探索を割り当てる。

中央担当は、道中の通常宝箱を拾わない。通常宝を運んで中央到達が後回しになるのを防ぐための選別であり、金宝箱なら取得する。中央担当を解除された仲間と、ほかの仲間は通常宝も拾う。運搬中の仲間に宝を捨てさせたり、全員を中央へ集めたりする処理は追加していない。

### 金宝箱と経路が分かっている場合

観測した金宝箱のID・セル・ワールド座標を使う。到達と搬出の既知経路があり、時間内に終えられる見積もりなら、所要時間が小さい仲間を選ぶ。金宝箱は通常宝の「全工程24秒／遠征45秒」の上限から外し、残り時間で判定する。

時間見積もりは既存と同じ **往路0.72秒/マス＋搬出1.05秒/マス＋余裕3秒**。前回の中央担当は比較コストを0.85倍として、僅かな差で交代させない。残り時間に入るかの判定には、割り引いていない見積もりを使う。

### 経路や金宝箱の現在位置が分からない場合

公開マップの中央ホールへ届くなら、まだ自部隊が訪れていないホール内のセルを確認する。ホールの範囲は公開 `KnownCellInfo.IsCentralHall` と `IsWalkable` から取得し、自部隊の公開現在セルだけで訪問を記録する。

まだ接続していない場合は、既知の開口から1歩で入れる未観測セルを中央へ向かう開拓先にする。比較コストは **既知の経路歩数×0.65＋中央へのマンハッタン距離**。既知ホール内の確認先は **経路歩数＋中心からの距離×0.25** で選び、担当間の比較には経路歩数を使う。座標差は誘導用であり、壁を通れたり、未知の先が接続していたりするとは仮定しない。

落ちた金宝箱を別の場所で観測し、まだそこまで接続していなければ、その観測位置を開拓の方向付けに使う。

## 解除と人数制限

- 金宝箱が運搬中と観測されたら、中央へ行って拾う担当を解除する。以後、落ちた金宝箱を再観測すれば再び回収を狙える。見えない敵の搬出は確定しない。
- 自部隊の金宝箱搬出は、個人AIの公開 `SXG_OnTreasureExported` フックで連絡し、その試合の中央探索を終了する。
- 金宝箱が未発見のまま、既知の歩ける中央ホール内を全て訪問した場合は中央探索を終了する。後で落ちた金宝箱を観測すれば回収候補になる。
- 未知経路を探す中央担当は、残り **30ゲーム内秒以下**で解除する。経路が既知でも、回収・搬出が残り時間に入らないと見積もられたら専任担当を出さない。
- 動ける手ぶらの仲間がいなければ、運搬やロックの終了まで新しい担当を出さない。KO中の仲間は選ばない。
- 中央担当がいる間、通常宝への新しい長距離遠征は出さない。すでに運搬している宝の帰還は維持する。

中央担当の通知は既存の護衛通知と同じ **0.36ゲーム内秒**で失効する。部隊が判断を更新しなくなれば、通常宝の取得を拒否し続けない。部隊破棄時に連絡帳の登録を解除する。
