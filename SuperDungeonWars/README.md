## 判断の流れ

1. 公開SXG APIから、メンバー・既知マップ・可視の宝箱を読み、運搬者へ帰還を指示する。
2. 手ぶらで動ける仲間から中央担当を最大1人確保する。金宝箱への既知経路があれば回収、経路が未知なら中央へ向かう開拓を優先する。
3. 残った仲間へ、既知経路4歩以内・全工程24秒以内の宝の回収を探索より先に割り当てる。
4. 拾うまで12歩以内・全工程24秒以内の短い回収を割り当てる。通常宝への長い回収は全工程45秒以内・同時に1人までで、中央担当がいる間は新規に出さない。
5. 回収・搬出の担当を確保した後、残った仲間へ支援・探索を割り当てる。
6. 目標の宝をIDで保持し、同じセルへ着いたらその宝の観測座標へ近づく。0.12秒周期で再計画する。

中央担当は途中の通常宝箱を拾わずに進む。金宝箱は通常宝の24秒・45秒上限の例外とし、回収から搬出までの見積もりが残り時間に入れば優先する。未知経路の開拓は残り30秒以下で解除する。金宝箱の運搬中を観測した場合、自部隊が搬出した場合、未発見のまま既知ホール内を全て訪問した場合も中央探索を解除する。落ちた金宝箱を後から観測すれば、その位置を回収候補にできる。条件と限界は [追加強化3の変更点](AIExperiments/Ariadne/UPGRADE3_CHANGES.md) を参照。

未観測セルは、観測済みセルの開口から入れる隣の1マスとしてだけ扱う。未知のセルを通り抜ける経路は推測しない。搬出口はゲーム規則にある4辺の中央で、帰還には観測済みで到達可能な入口だけを使う。配布ルールでは、相手側の入口へ運んでも搬出した自チームの得点になる。敵が集まる入口へ運ぶ危険は別途考慮する。

宝箱は見失っても位置を記憶するが、近くへ来ても見えない場合、または最後の観測から45秒経った場合に候補から外す。同じセルまで近づいた宝には、観測したワールド座標への移動を指示して接触を狙う。

個人の攻撃は、攻撃可能な候補の中で味方運搬者に近づいた敵を優先し、次に敵の宝箱運搬者、通常敵の順で狙う。運搬者への脅威は公開観測から3ワールド単位以内・既知の接続2歩以内で判定する。自分が宝を運んでいる間は搬出を優先する。

移動を伴う近場の護衛・迎撃へは手の空いた仲間を最大1人だけ回す。護衛3歩・敵運搬者への迎撃2歩以内で、追跡期限は2.4秒（0.12秒周期で終了を判定）。終了後2.4秒は次の追跡を始めない。4マス以内で回収し時間内に搬出できる宝がある仲間は、任意の追跡より回収を優先する。敵を見失った場合も回収・探索へ戻る。

運搬中に見える手ぶらの敵がいる場合は、そのセルと既知接続2歩以内へ危険コストを加える。帰還は各再計画時点で最短より6歩以内、残り時間内に搬出できる見積もりの経路を候補にする。候補がなければ従来の最短帰還へ戻す。敵の動きによる寄り道や、反撃による行動ロックが増える可能性はある。詳細は [追加強化1の変更点](AIExperiments/Ariadne/UPGRADE1_CHANGES.md) を参照。

## 主な調整値

| 値 | 意味 |
|---|---|
| 思考間隔0.12秒 | 全員の経路探索を毎フレーム繰り返す負荷を抑える |
| 通常宝1、中央宝2.7 | 平均100点・270点から見積もる相対価値 |
| 近場4歩、短い回収は往路12歩・全工程24秒 | 探索より先に回収担当を確保する条件 |
| 長い回収は全工程45秒以内、同時に1人 | 遠くの宝へ全員を出すのを防ぐ |
| 中央担当は最大1人、未知経路の開拓は残り30秒まで | ほかの仲間の通常宝回収と、終盤の搬出時間を確保する |
| 中央担当の前回担当を比較コスト0.85倍 | 担当が毎思考入れ替わるのを抑える。搬出可能時間の判定は割り引かない |
| 往路0.72秒/マス、復路1.05秒/マス、余裕3秒 | 制限時間内に回収と搬出ができるかを概算する |
| 近場以外で同じ宝の担当を1.15倍、探索の前回目標を1.18倍 | 小さな評価差による目標変更を抑える |
| 他の担当目標から3マス以内は探索評価0.25倍 | 探索先を分散させる |

時間の概算は、120秒制、セル間隔2、通常速度3、運搬速度2を前提とする。衝突や敵の妨害を正確に予測するものではなく、ルールが変わる場合は各係数の見直しが必要。

通常は回収・搬出へ最大3人を使い、探索等へ1人を残す。近場回収はその人数上限を超えて割り当てられるが、先に確保した中央担当は上書きしない。近場回収の条件は [追加強化2の変更点](AIExperiments/Ariadne/UPGRADE2_CHANGES.md)、今回の優先順の変更は追加強化3の記録にまとめた。
